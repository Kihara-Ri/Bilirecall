# BiliRecall 隐私政策

最后更新：2026-09-20

BiliRecall（下称「本扩展」）是一个把 B站 视频沉淀到你自己 Notion 知识库的浏览器扩展。
本政策说明本扩展访问哪些数据、把它们发到哪里、以及你如何删除它们。

**一句话版本：本扩展不使用服务器、不做统计、不做广告，也不向开发者回传任何数据。
所有记录都保存在你自己浏览器的 `chrome.storage.local` 里；只有在你主动开启对应功能后，
数据才会发送到你自己配置的 Notion / AI 服务 / Webhook 地址。**

## 一、本扩展访问什么

| 数据 | 何时 | 用途 |
| --- | --- | --- |
| B站 视频页面的公开信息（视频号、标题、UP主、分区、时长、封面、简介、字幕文本） | 你打开 `www.bilibili.com` 的视频 / 番剧 / 播放列表页时 | 建立本地记录、生成摘要、写入你的知识库 |
| 你账号下的 B站 列表：观看历史、点赞、收藏 | 你点击「更新历史」或开启了自动同步时 | 把 B站 会过期的历史保存成本地长期归档 |
| 你账号对某个视频的互动状态（点赞 / 投币 / 收藏） | 你打开视频页、或使用归档同步时 | 显示真实状态；B站 官方页面之外不推断 |
| 页面上你正在播放的视频进度 | 播放中的视频页 | 记录看到哪里，用于「继续播放」 |
| 你的 B站 账号 mid | 同步历史时 | 仅用于检测账号是否被切换，避免把两个账号的数据混在一起 |
| 你填写的凭据（Notion Integration Token、AI API Key）与你写的笔记 | 你填写 / 输入时 | 按你的配置调用对应服务；凭据只存在本地 |

不访问：浏览历史（只处理 `bilibili.com` 视频相关页面）、其它网站内容、密码、支付信息、
cookie 内容（本扩展不申请 `cookies` 权限，也不读取或导出 cookie 值；带登录态的请求由浏览器
自身按 B站 域发送）。

## 二、数据会离开你的设备吗

只有你主动开启的功能会把数据发出去，接收方都是**你自己配置**的：

| 功能 | 发送内容 | 接收方 |
| --- | --- | --- |
| 写入 Notion（默认关闭） | 视频元信息、字幕正文、AI 摘要、你的笔记、封面图 | 你填写的 Notion integration 所连接的页面 / 数据库（`api.notion.com`） |
| AI 摘要（默认关闭） | 视频标题、UP主、分区、简介、字幕正文、你的笔记 | 你填写的 OpenAI 兼容端点（域名由你决定，授权时才申请该域名权限） |
| Webhook（默认关闭） | 该视频的完整记录 JSON | 你填写的 URL |

除此之外没有任何外部请求：不使用开发者服务器，没有统计、埋点、崩溃上报、广告或推荐 SDK，
不会把数据卖给或分享给第三方，也不会用于与扩展单一用途无关的目的。

## 三、存储与删除

- 数据只存在本机 `chrome.storage.local`（扩展自己的存储区）。
- 逐条删除：在弹窗或管理页的「知识库 / 历史记录」里用行的更多菜单「从本地历史移除」或删除记录。
- 全部删除：卸载扩展，或在 `chrome://extensions` 中清除该扩展的数据。
- 已经写入 Notion / 你的 AI 服务的数据由那些服务按其自身政策保存，需要你在那边删除；
  本扩展不保留副本。

## 四、权限用途

| 权限 | 用途 |
| --- | --- |
| `storage` / `unlimitedStorage` | 在本机保存记录、字幕与设置；字幕正文较长，需要超出默认配额 |
| `alarms` | 后台同步队列的重试与续传（MV3 不保证后台常驻） |
| `tabs` | 识别当前标签页是不是 B站 视频页（只读取 URL 用于匹配视频号） |
| `notifications` | 可选：写入 Notion 成功时的桌面通知 |
| 主机权限 `*.bilibili.com` / `*.hdslb.com` | 读取视频信息、互动状态与字幕 |
| 主机权限 `api.notion.com` | 你开启 Notion 写入时创建页面 |
| 可选主机权限（`https://\*/*`、`http://localhost/*`、`http://127.0.0.1/*`） | 只在你点击「测试 AI 连接 / 授权并测试 Webhook」时按需申请你填写的那个域名 |

## 五、儿童与合规

本扩展面向普通用户收集与整理公开视频内容，不面向儿童，不收集年龄信息，不做广告投放。
