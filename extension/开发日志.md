# 开发日志

## 未发布 — 2026-09-24（历史同步自动调度）

- 修复「新历史总是对不上」的根因：`HISTORY_ALARM` 只在 UI 发来 `sync-bilibili` 时创建、任务一结束就被清除，它被当成了续传唤醒器而不是定时调度器，导致没有任何常驻机制开启新一轮同步——新历史只有打开插件页面才会被拉取。现在闹钟与「自动更新历史」设置绑定常驻（`ensureHistoryAlarm`），每次到点先按节流规则尝试开新任务再驱动批次（`ensureHistoryTick`），浏览器启动 / 安装 / 打开自动更新开关都会立即触发一轮同步。
- 失败任务不再永久停摆：`start(false)` 以前只要上一个任务 `state === 'error'` 就直接跳过，一次网络抖动或风控（-352）就会把同步链打死。任务新增 `failedAt`，失败与完成共用同一个 5 分钟节流窗口（`SYNC_INTERVAL_MS`）：窗口内不重试（不对着风控连续撞），到期由闹钟自动从原游标续跑；手动「更新历史」的立即重试语义不变。
- 互动刷新改为按陈旧度增量：relations 阶段以前每轮对全库逐条（约 650ms/条）重查赞/币/藏，库一大每轮要跑十几分钟才轮到下一轮历史拉取。现在只补查超过 6 小时（`RELATION_STALE_MS`）没查过的记录和本轮新入库的记录，同步周期回到 5 分钟一轮。
- 仓库改头换面：移除已被扩展取代的 Python v1/v2 全部代码（`workflow/`、`src/`、`tests/`、`GUI/`、notebook、`pyproject.toml` 打包配置与根目录旧文档）、Python CI 换成 Node 22 的 `npm run verify`、`.gitignore` 重写为扩展项目版，README 移除 Python 章节并补充自动同步的新行为。
- 新增测试：退避窗口内失败任务不重试 / 窗口过后自动续跑（保留游标）、互动刷新跳过 6 小时内已查过的记录。`npm run verify` 全部通过（26 个文件、221 项测试）。

## 未发布 — 2026-09-20（审查整改）

- 修复笔记栏打不出空格：textarea 以前直接绑在落库数组上，每次按键都要 `split+trim+join` 转一遍，刚敲下的空格（行首、行尾、只敲了空格的空行）在这一次往返里被吞掉。改为编辑器持原文、规范化只发生在写入前（新增 `lib/notes.ts`），并让后台回包与当前原文等价时保留原文，自动保存后的轮询不会再抹掉行尾空白。
- 移除未使用的 `cookies` 权限：登录态本来就来自 `/x/web-interface/nav` 的 `isLogin`，全仓库没有任何 `chrome.cookies` 调用，README 的说法与实现不符。
- 外部请求统一加超时：AI（15s/60s）、Notion（30s）、封面上传（60s）、封面下载（15s）、Webhook（10s）、字幕 CDN（15s）复用 `lib/http.ts` 的常量。以前一个挂住的端点会占着按记录锁不放，同一视频的笔记保存先撞上界面 15 秒预算，报「后台响应超时」而写入事后其实成功。
- Webhook 移到记录锁之外发送，并检查响应状态码：慢端点不再阻塞同一视频的其他写入，失败也不只留在 service worker 控制台。
- 设置页补主机权限入口：新增「授权并测试」（申请该域名权限 + 真实发送一条测试消息），AI/Notion 的权限申请统一走同一个 `ensureOrigin`；manifest 的可选主机权限补上 `http://localhost` 与 `http://127.0.0.1`，本地模型（如 Ollama）不再因为权限申请静默失败而完全不可用。
- 页面桥接改为当作不可信输入：新增 `lib/bridge.ts`，MAIN world 的消息先在内容脚本、再在后台各校验一次（BV 号格式、正整数 aid/cid、文本与字幕轨数量截断、观看数值夹取、动作只认 bilibili.com 上的四个端点）。此前任何跑在 bilibili.com 的脚本都能伪造 `window.postMessage` 建立记录、触发 AI/Notion 写入；同时删掉了内容脚本里重复的 `classifyAction` 副本，改为复用 `lib/events.ts` 的唯一实现。
- 心跳与轮询降载：内容脚本只在位置/累计观看真的变了才上报（暂停的后台标签页不再每 10 秒唤醒 service worker 并写一次存储）；后台对重复心跳不写库（不会再每 10 秒顶掉归档版本号、让管理页跟着重读整份归档）；`stats` 按归档版本号缓存，面板每 1.5 秒的轮询不再重读全部记录与字幕。
- 新增 `docs/privacy.md`：可直接作为商店隐私政策 URL 的数据清单与外发说明。
- 文档：仓库根 `README.md` 重写为项目主 README（功能一览 + 字幕一致性的根因与八条防线 + 快速开始 + 文档导航，Python v2 降级为文末历史实现）；本 README 补同名「字幕一致性」章节与新增模块表行，并把测试数量改为实际值。
- 验证：`npm run verify`（26 个文件、219 项测试）、`npm run e2e`（61 项）、`npm run ui-audit`（含新增 content/heartbeat 与 options/webhook 用例）、工作区 31 项浏览器检查全部通过。新增测试：笔记空格回归（先失败后通过）、超时、桥接校验、统计缓存、发布标准（权限最小化/图标/无远端代码）。
